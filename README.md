# VR Lab · 밸류 리밸런싱 연구실

모바일을 우선으로 만든 정적 백테스트 웹앱입니다. 라오어의 공개 VR 기본공식을 참고한 **독립적인 일별 종가 연구 모형**입니다. 공식 지정가 예약매매의 장중 체결이나 실력공식을 재현했다고 주장하지 않습니다.

## 기능

- TQQQ·QLD·SOXL 선택, 시작·종료일 및 초기자금 설정
- V·Pool·G·밴드·현금 사용 한도 조절
- 거치식·적립식·인출식, 비용·현금 이율·사이클 설정
- 선택 ETF 100%, 기존 QLD70/SCHD15/IAU15 주간·월간·분기, QLD100과 비교
- 현금 유입·유출을 제거한 TWR CAGR·MDD, 순손익·XIRR
- G × 밴드 35개 조합 또는 현금 비중을 포함한 175개 조합 탐색
- 같은 보유기간으로 최대 5,000개 서로 다른 시작일 반복 검증
- 터치 가능한 성장지수·낙폭·Pool/V 차트, 확대 보기
- 거래 일지·CSV 내보내기·사용자 조정종가 CSV 가져오기
- 320px와 390px 너비에서 검증한 접이식 설정과 하단 실행 버튼

서버·로그인·API 키가 필요 없습니다. 초기 가격 스냅샷을 제외한 계산과 업로드는 브라우저 안에서 실행합니다. Web Worker로 계산해 긴 반복 검증 중에도 화면이 반응합니다. 외부 폰트나 차트 CDN에 의존하지 않습니다.

## 로컬 실행

Node.js 22 이상 권장. 별도 의존성 설치가 없습니다.

```bash
npm run dev
# http://localhost:5173
npm test
npm run check
```

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main**, **/(root)**를 선택합니다. `.nojekyll`이 포함되어 있고 모든 자산·Worker·JSON 경로가 상대 경로여서 프로젝트 하위 경로에서 동작합니다.

## 데이터

`data/prices.json`에는 Yahoo Finance 일별 배당·분할 조정종가와 출처 URL·취득시각·원본 해시가 들어 있습니다. 기본 표본은 SCHD와의 공통 이력을 사용한 **2011-10-20~2026-10-30, 3,779거래일**입니다.

가격을 수동 갱신하려면 Python 3 표준 라이브러리만으로 다음을 실행하고 변경을 커밋합니다. 자동 예약 실행은 설정하지 않았습니다.

```bash
python3 scripts/update_data.py
```

CSV 가져오기는 다음 형식입니다. 실제 조정종가를 사용해야 합니다.

```csv
Date,TQQQ,QLD,SOXL,SCHD,IAU
2024-01-02,45.1,35.2,28.1,24.2,38.5
2024-01-03,44.8,35.0,27.6,24.3,38.7
2024-01-04,45.4,35.4,28.0,24.5,38.9
```

Date와 선택 투자 ETF 열은 필수입니다. 비교 가격이 없으면 해당 비교를 생략합니다. 날짜는 유효한 YYYY-MM-DD 오름차순, 중복·누락 없는 양수 가격이어야 합니다. 가져온 CSV는 서버에 전송하지 않습니다.

## 계산의 정확한 범위

1. 초기 예산에서 Pool을 분리하고 나머지를 매수합니다. 초기 V는 거래비용을 내기 전 주식 투자 예산입니다. 초기 매수 비용도 부담합니다.
2. 각 사이클에 `다음 V = 현재 V + 사이클 갱신 직전 Pool/G + 납입금 − 실제 인출금`을 적용합니다. 현금 이자는 선택한 고정 연이율로 경과 일수에 따라 복리 계산합니다.
3. 매 거래일 종가 평가금이 밴드 밖이면 같은 종가로 밴드 경계 또는 V까지 조정합니다. 소수점 매매입니다. 장중 사다리 주문을 모델링하지 않습니다.
4. 매수는 현금 잔액과 사이클 시작 시 정한 사용 한도 중 작은 범위 안에서 진행합니다. 한도는 수수료를 포함한 지출 기준입니다. 사이클 중 매도대금이 들어와도 그 사이클의 이미 정한 매수 예산을 늘리지 않습니다.
5. 인출에 현금이 부족하면 주식을 팔아 마련합니다. 전체 자산으로도 부족하면 미달액을 표시합니다. V가 0이 되면 밴드 거래를 중단하고 보유자산 시가평가는 계속합니다.
6. 비교 전략은 같은 초기 예산·날짜·납입·인출을 사용합니다. 고정 비중 비교는 달력상 각 주·월·분기 마지막 거래일 종가에 리밸런싱합니다. 새 납입은 목표 비중에 따라 투자하고 인출 재원은 비례 매도합니다. 종료일에 강제 청산하지 않습니다.
7. 일별 `r = (마감 자산 − 순입금)/전일 자산 − 1`을 연결한 TWR로 CAGR·MDD를 계산합니다. 초기 거래비용도 성장지수에 포함합니다. MDD는 성장지수의 이전 최고점 대비 일별 하락폭이며 추가납입·인출이나 장중 낙폭을 섞지 않습니다.
8. 순손익 = 최종 자산 + 누적 인출 − 초기자금 − 추가납입입니다. XIRR은 각 입출금 시점을 반영한 별도 개인 투자수익률입니다.
9. ETF 운용비용은 실제 가격에 포함됩니다. 한국 세금·배당 원천징수·환율·환전비는 제외합니다. 분배금은 해당 ETF에 재투자된 것으로 간주합니다.
10. 탐색 결과는 같은 과거에서 고른 사후 결과입니다. 반복 검증은 시드 20261102로 시작일을 중복 없이 뽑지만 구간은 서로 겹칩니다. 독립 시행 수나 미래 승률을 의미하지 않습니다.

## 검증

Node 내장 테스트로 가격 비율과 단순 보유 비교, 납입/인출의 TWR 처리, 인출 재원 부족, 사이클 매수 한도, V 갱신, 수수료 자기자금 회계, 독립 보유금액 계산, 알려진 XIRR, 날짜·데이터 검증, 무작위 표본 재현성을 검사합니다. 기본 데이터에서 기존 QLD70/SCHD15/IAU15 분기 전략의 무비용 성과가 앞선 Python 실험(CAGR 약26.7441%, MDD 약−49.8952%)과 일치하는지도 대조합니다.

## 주요 파일

- `engine.js`: 브라우저·Node 공용 순수 계산 엔진
- `worker.js`: 백테스트·스윕·반복 검증 작업
- `app.js`: 입력·차트·CSV·상태 관리
- `styles.css`: 모바일 우선 화면과 작은 화면 보정
- `tests/engine.test.mjs`: 계산 검증
